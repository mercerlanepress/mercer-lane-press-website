Subcontracting changes the estimator's task.

You may no longer be developing the specialist installation cost internally, but you still need to know whether the external price matches the scope you intend to carry.

Price and scope are different questions. A small number is not automatically a usable number.

## Define the quote scope before asking for a price

A weak request is to send a drawing and ask, "Can you price this?"

A stronger request identifies the commercial information needed to compare the response with the estimate.

Depending on the package, ask the bidder to make visible:

- the project documents and drawing issue used;
- inclusions;
- exclusions;
- allowances;
- qualifications;
- owner- or contractor-supplied items;
- delivery or mobilization treatment;
- important interfaces with your work or another trade;
- permit or inspection treatment where relevant;
- quote validity.

This is not about telling a specialist how to perform regulated or technical work. It is about defining the commercial boundary of the quotation.

## Use five scope classifications

When the quotes arrive, classify important scope points.

**INCLUDED** — the quotation clearly covers it.

**EXCLUDED** — the quotation clearly says it does not.

**ALLOWANCE** — the quotation carries a provisional amount rather than a fully defined price.

**CLARIFICATION** — responsibility or treatment is not clear.

**GAP** — required work appears not to be carried by anyone.

The gap category matters because two individually reasonable quotations can still leave an interface unpriced.

## Compare horizontally, not one quote at a time

Reading each quotation from top to bottom and then sorting the totals can hide major differences.

Instead, put the important scope points side by side.

A comparison might include:

| Review point | Bidder A | Bidder B | Bidder C |
| --- | --- | --- | --- |
| Current drawings acknowledged |  |  |  |
| Defined package complete |  |  |  |

| Important exclusion |  |  |  |
| Quote validity |  |  |  |
| Usable as submitted |  |  |  |

The exact fields change by trade. The point is to compare the same questions across bidders.

## Check document currency before price ranking

A lower quote based on an earlier drawing issue may not be comparable with a higher quote based on the current project information.

Before using the total, confirm that the bidder priced the documents you expect them to have priced.

A quotation can have been entered correctly in the estimate and still become stale later.

That is why document issue and quote validity belong both in the initial comparison and in the final bid review.

## Run the interface gap test

Ask what work exists between your scope and the subcontractor's scope.

For example:

- Who supplies the equipment?
- Who installs it?
- Who prepares the opening or support?
- Who makes the connection?
- Who provides controls or accessories?
- Who finishes around the installation?
- Who handles cleanup or closeout?

If one specialist excludes a connection and the adjacent trade excludes the same interface, the estimate can contain a gap even though both quotations are internally correct.

## Do not label a bidder "low" too early

Price ranking is meaningful only after the quotations are sufficiently comparable.

That does not mean a higher quotation should be selected automatically. It means the estimator should understand the scope differences before deciding what the totals mean.

A lower quotation may become fully usable after clarification. A higher quotation may contain work that another bidder excluded.

Record the clarification and update the comparison instead of relying on memory of a phone call or email.

## Supplier-designed packages deserve the same discipline

The same commercial logic applies to supplier-priced or supplier-designed assemblies.

Record enough information to answer:

- what project is this for?
- which document issue?
- what quantity?
- what is included?
- is delivery included?
- when was the quote issued?
- when does it expire?
- which interfaces remain outside the package?

A package total is much more useful when the estimate can also show what that number buys.

## Final quote-normalization check

Before a subcontract amount enters the final estimate:

- compare bidders on the same scope questions;
- confirm current documents;
- identify complete, partial, and unclear package boundaries;
- record exclusions, allowances, interfaces, and qualifications;
- confirm delivery or mobilization where relevant;
- confirm quote validity;
- identify gaps;
- update any quotation that changes after clarification.

Then carry the selected scope-aligned amount into the estimate.
