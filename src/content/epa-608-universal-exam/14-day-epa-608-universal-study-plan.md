The 14-day plan in *EPA 608 Universal Certification Exam Prep 2027* is built around a simple idea: find the weak section early, keep the four equipment categories separate while learning, then finish with mixed closed-book practice.

## Day 1: Diagnostic

Take the **40-question diagnostic**.

Do not just record a total score. Build a weak-area list by section:

- Core
- Type I
- Type II
- Type III

That list decides where extra review time should go.

## Days 2–3: Core

**Day 2:** certification scope, environmental effects, phaseout milestones, venting, and refrigerant sales.

**Day 3:** recover/recycle/reclaim, recovery, evacuation, gauges, safety, cylinders, and nitrogen.

Keep the language exact. Recovery is not evacuation, and similar-looking numbers need to stay attached to the rule they belong to.

## Day 4: Type I

Study:

- the small-appliance definition;
- the 80% and 90% recovery cases;
- the 4 in Hg vacuum alternative;
- system-dependent recovery;
- compressor condition;
- access to both high and low sides when the compressor is inoperative;
- temporary solderless access fittings.

## Days 5–6: Type II

**Day 5:** learn the current evacuation table and reproduce it from memory twice.

**Day 6:** focus on leak repair, records, the 30-day and 120-day timelines, and the current 30/20/10/10 leak-rate pattern described in the book.

This is a high-confusion section because appliance class, charge size, recovery-equipment date, and repair type can all change which number applies.

## Days 7–8: Type III

**Day 7:** learn the 25 mm Hg absolute recovery endpoint, leak direction, purge-unit purpose, and controlled pressurization concepts.

**Day 8:** review liquid and vapor recovery, heating chiller oil to 130 F before removal, water-freezing risk during deep evacuation, vapor-first recharge, and the correct charging connection described in the Type III outline.

## Days 9–10: Section drills

**Day 9:** complete the Core and Type I detailed-practice sections.

**Day 10:** complete the Type II and Type III detailed-practice sections.

Read every rationale, including the ones you answered correctly if the distractors felt plausible.

The value is not just knowing which letter is right. It is knowing why the nearby rule, unit, percentage, or legacy value is wrong in that specific situation.

## Day 11: Number Collision Matrix

Study the book's Number Collision Matrix.

Then make a one-page handwritten memory sheet.

Do not write isolated numbers. Write the **number + object + condition** together.

For example, “80%” by itself is weak memory. “Small-appliance recovery when the compressor is inoperative or equipment is pre-1993” is usable memory.

Use the [EPA 608 numbers-to-know guide](/epa-608-universal-exam/epa-608-universal-numbers-to-know/) as a compact review.

## Day 12: Full Mock Exam 1

Take Mock Exam 1 closed book.

Score Core, Type I, Type II, and Type III separately.

The book's study target is at least **21/25 in every section**.

## Day 13: Repair weak areas

Do not reread the whole book.

Start with the section furthest below the readiness target.

For each miss, identify the exact thing that made the wrong answer tempting:

- number;
- date;
- pressure unit;
- appliance class;
- rule condition;
- current versus legacy value.

Retake the missed concepts as short oral questions.

## Day 14: Full Mock Exam 2 + final logistics

Take Mock Exam 2 closed book.

Then use the final-day quick review and confirm provider logistics.

Check the [final-day EPA 608 checklist](/epa-608-universal-exam/epa-608-final-day-checklist/) before relying on old notes or assumptions.

## If two weeks is too compressed

The same book also includes a 21-day plan.

It spreads the Core foundation over six days, Type I over two, Type II over four, Type III over three, then uses the remaining days for the Number Collision Matrix, mixed recall, two mocks, weak-section repair, and light final review.

The point is not to finish pages on schedule. The point is to arrive at mixed practice with all four sections sufficiently distinct in memory.
